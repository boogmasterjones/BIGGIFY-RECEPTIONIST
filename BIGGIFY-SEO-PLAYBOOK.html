Biggify — Local SEO Delivery Playbook

Step-by-step instructions for delivering the Local ($449/mo) and Growth ($749/mo SEO + automation) packages.

Last updated: 2026-08-15

How to use this playbook

  • Local clients follow the Local track only.
  • Growth clients follow the Local track PLUS the Growth add-ons marked [+ GROWTH] throughout — Growth is a superset of Local (more geography, more content, active off-page, and the automation attribution loop).
  • Each phase lists Goal → Tasks → Done when. Do the phases in order; don't skip the foundation.
  • Timeline assumes local SEO's real ramp: foundations in month 1, momentum by month 3, meaningful ranking gains by months 4–6. Set this expectation with the client on day one — impatience in months 1–3 is the #1 reason SEO clients cancel.

Phase 0 — Onboarding & Audit (Week 1)

Goal: Get access to everything, understand the business, and baseline where they stand today.

Tasks

  1. Kickoff call — confirm services, service area(s), target towns, main competitors, average job value, and their busy/slow seasons.
  2. Collect access (send a single checklist):
    • Google Business Profile (add yourself as manager)
    • Website admin/CMS + hosting login
    • Google Analytics + Google Search Console (create if missing)
    • Existing directory logins (Yelp, Angi, etc.)
  3. Baseline audit — record current state so you can prove progress later:
    • Current keyword rankings for core "[service] + [town]" terms
    • GBP completeness score + current review count/rating
    • Website technical health (mobile, speed, HTTPS, indexed pages)
    • NAP (Name/Address/Phone) consistency across the web
  4. Set up tracking: rank tracker for the target keywords, Search Console, GBP Insights.
  5. [+ GROWTH] Provision the automation platform — spin up their co-branded dashboard, configure the AI receptionist, and set up call tracking so every SEO-driven call is logged and attributable.

Done when: you have all access, a documented baseline snapshot, and (Growth) a live dashboard + tracked phone number.

Phase 1 — Foundation (Month 1)

Goal: Fix the fundamentals. This is what actually moves local rankings first.

Google Business Profile (the single biggest local lever)

  1. Claim & verify the profile.
  2. Fill everything: primary + secondary categories, full service list with descriptions, business description, hours, service areas, attributes.
  3. Upload 10–20 quality photos (team, work, before/after, logo, storefront/truck).
  4. Set up the review request flow (a simple link/QR the owner texts to happy customers).
  5. Post the first GBP update (offer, project, or tip).

On-site fundamentals

  1. Fix NAP consistency — exact same name, address, phone everywhere.
  2. Optimize the homepage + core service pages: title tags, H1s, meta descriptions targeting "[service] in [primary town]".
  3. Add LocalBusiness schema markup.
  4. Technical pass: mobile-friendly, HTTPS, fast load, no broken pages, submit sitemap to Search Console.

Citations

  1. Build/clean foundational citations — Google, Bing, Apple Maps, Yelp, BBB, Angi, Facebook, and the top 2–3 industry-specific directories (e.g., Houzz for design, HomeAdvisor for trades). NAP identical on every one.

Content

  1. Publish 1–2 cornerstone pages (Local) — the primary service page(s), fully optimized.
    • [+ GROWTH]: publish 4–6 pages — one strong location page per target town ("[Service] in [Town]") plus top service pages.

Done when: GBP is 100% complete, core service pages are optimized with schema, foundational citations are live and consistent, and the first content is published.

Phase 2 — Momentum (Months 2–3)

Goal: Build content velocity, reviews, and early authority so rankings start climbing.

Recurring monthly tasks (both tiers)

  1. Content: Local = 1–2 pages/mo; [+ GROWTH] = 4–6 pages/mo (rotate: location pages, service deep-dives, local FAQ/blog targeting "[service] near me / in [town]").
  2. GBP: post weekly, answer Q&A, add fresh photos, respond to every review within 24h.
  3. Reviews: actively drive new reviews.
    • Local = keep the request flow running.
    • [+ GROWTH] = managed campaign — follow up after every completed job, aim for a steady drip (target: 2–4 new reviews/mo minimum).
  4. Citations: expand into secondary + niche directories; fix any inconsistencies flagged.

[+ GROWTH] Off-page (links)

  1. Start an active link-building campaign: local sponsorships, chamber of commerce, supplier/partner links, local press, and 1–2 quality guest/citation links per month.

[+ GROWTH] Attribution

  1. Turn on the proof loop: connect tracked calls → receptionist bookings → jobs in the workspace, so the monthly report can show "SEO drove X calls, Y booked, Z closed."

Done when: content is publishing on cadence, reviews are growing monthly, and (Growth) links + the attribution loop are running.

Phase 3 — Ranking Gains & Proof (Months 4–6)

Goal: Convert the groundwork into visible ranking movement and a hard ROI story.

Tasks

  1. Re-audit rankings vs. the Phase 0 baseline — document movement on target keywords and the GBP "map pack" positions.
  2. Double down on what's ranking: refresh and expand the pages gaining traction; internal-link them.
  3. Fill gaps: any core keyword still stuck → new dedicated page or more links pointed at it.
  4. Keep all recurring tasks running (content, GBP, reviews, citations, [+ GROWTH] links).
  5. Deliver the milestone report:
    • Local: rankings up, GBP views/calls/direction-requests up, reviews up, traffic up.
    • [+ GROWTH]: all of the above + the attribution story — leads → booked → closed → estimated revenue. This is the number that renews the contract.

Done when: you can show clear ranking improvement + growth in GBP actions, and (Growth) a dollar-figure ROI from attributed jobs.

Phase 4 — Maintain, Expand & Upsell (Month 6+)

Goal: Hold rankings, keep producing ROI, and grow the account.

Recurring

  • Keep the monthly engine running (content, GBP, reviews, citations, [+ GROWTH] links + attribution).
  • Monthly report every month, no exceptions — visibility is what keeps them paying.

Grow the account

  • Local → Growth: once Local is ranking in its one town, pitch the upgrade — "You own [Town]; let's take the next 3–5 towns and add the system to catch and prove every call." The results in town #1 are the proof that sells the expansion.
  • Growth → Dominate: for competitive metros / multi-location.
  • Automation expansion: upsell invoicing, team/payroll, and statistics modules as the client grows.

Golden rules

  1. Set the timeline expectation on day one. "Months 1–3 build the foundation; real ranking gains show months 4–6." Prevents the early cancellation that kills SEO retainers.
  2. GBP first, always. For local, the Google Business Profile moves the needle faster than anything else — perfect it before chasing links.
  3. Report every month, even when it's slow. Silence reads as "not working." Show the leading indicators (reviews, GBP views, content shipped) while rankings cook.
  4. For Growth, the attribution report is the product. SEO's fatal flaw is being unprovable — the calls → booked → closed loop is what makes Growth worth $749 and what makes it renew.
  5. Never promise specific rankings or timelines you can't control. Promise the work and the leading indicators, not "#1 on Google by month 2."
